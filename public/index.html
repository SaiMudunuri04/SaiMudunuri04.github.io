Honeywell

AI/ML Engineer

Oct 2024 — PresentAtlanta, GAContract

GenAI · LLM agents · Industrial IoT

  • Built a production RAG assistant over 10,000+ internal engineering documents with Amazon Bedrock (Titan embeddings) and OpenSearch hybrid search — BM25 + vector, metadata filters, reranking, citations — cutting latency from 6 s to 2.3 s −62%.
  • Developed LangGraph agents automating enterprise workflows across 20+ authenticated FastMCP tools and internal APIs, with scoped permissions plus schema and output validation that block invalid tool calls before execution.

  • Implemented LLM evaluation and tracing with LangSmith, RAGAS, and DeepEval to catch hallucinations, retrieval failures, and invalid tool calls; improved reliability through trace-level analysis and retrieval tuning.
  • Automated model releases with Terraform, Helm, Argo CD, GitHub Actions, and SageMaker Pipelines — release time 2 days → 4 hours with canary rollouts.
